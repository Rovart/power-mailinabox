WKD Management

WKD (Web Key Directory) is an experimental feature that allows users to authoritatively publish their public PGP keys on the web, via HTTPS. Unlike other solutions (like public keyservers), the owner of the domain has some degree of control over what keys are published, so there is more certainty that a key actually belongs to its owner.

As of this version, there is no support for WKS. This may or may not change in the future.

Emails hosted by this box

This box can serve keys to any email address hosted by this box, be it a user or an alias, granted that the key has one or more user ids with matching emails. You can add keys in PGP Keyring Management.

Hosting somewhere else

If you have a separate server to host WKD, you can still use it instead of this box on a per-domain basis.

This box uses the Advanced Method to serve the keys. For example, to host your @some.example.com keys, you can add an A, AAAA or CNAME record for openpgpkey.some.example.com. It will override the box's records.

There's not a way to “disable” WKD at the moment — but if you don't want to publish keys, or if you want to use the Direct method somewhere else, you can always set the records to an unreachable destination (for example, an A record to 0.0.0.0).
